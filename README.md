## AsureDataPack

Датапак, добавляющий новые крафты а также теги, использующиеся в работе других плагинов проекта Asure Nova.

---

## Сборка

Чтобы запустить сборку, скопируйте проект и запустите сборку через `gradle pack-zip`.\
Скомпилированный артефакт (архив) будет находиться в папке `build/out/`.

---

## Поддержка

Данный датапак разрабатывался для конкретного проекта. Многие возможности датапака были созданы с целью закрыть определённую нишу в
контенте, и могут являться рудиментарными для остальных проектов. При необходимости каждую конкретную функцию датапака можно отключить или перенастроить.

В связи с предназначением датапака услуги по его поддержке предоставляются только в рамках оригинального проекта. Для получения
поддержки (исправление багов, добавление возможностей) в рамках стороннего проекта, вы можете обратиться к автору датапака и оформить заказ консультации.
